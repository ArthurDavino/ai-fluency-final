## Built with AI

I built this whole program with Claude at my side, inside normal conversations, not by writing a model myself. It helped me design instructions, draft documents, and reason through failed test cases. What I verified myself, every time: I wrote the test cases before building, I ran them against real data and real files, I read every result myself, and I decided when something was actually fixed.
